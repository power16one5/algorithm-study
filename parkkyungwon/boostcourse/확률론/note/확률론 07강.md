### 도박꾼의 파산
두 도박꾼이 한 게임에 1달러씩 걸고 한쪽이 파산할 때까지 게임을 한다. 각 게임은 독립이며, 한 게임에서 A가 이길 확률을 p, b가 이길 확률을 p - 1 = q로 정의한다.

- 도박꾼 둘이 가진 돈은 총 N이며 외부에서 돈이 더 추가되는 경우는 없이 폐쇄적이다.
- A는 i 달러, B는 N - i 달러를 가지고 시작한다.
- 어느 한쪽이 파산할 때까지 게임한다.

B가 파산하여 A가 승리할 확률은 얼마나 될까?

수직선으로 표현하면 i에 게임을 이기면 i+1으로 이동하고 지면 i-1로 이동하는것으로 표현한다.

$$
|---------|---|---|---------| \\
0 \kern {8em} i-1 \kern {2.5em} i \kern {2em} i+1 \kern {8em} N
$$

$p_i$를 A가 i달러로 시작하여 게임을 이길 확률로 정의하면 점화식으로 아래와 같이 표현 가능하다.
$$
p_i = p \times p_{i+1} + q \times p_{i-1}
$$

이 식은 계차방정식이다. 

$p_i$를 $x^i$, 지수 형태로 추측해보자.
$$
p_i = x^i \\
\begin{aligned} \\
x^i &= px^{i+1} + qx^{i-1} \\
x^i \times \frac {1} {x^{i-1}} &= ( px^{i+1} + qx^{i-1} ) \times \frac {1} {x^{i-1}} \\
x &= px^{2} + q \\
0 &= px^{2} - x + q \\
\end{aligned} \\
\\
x = \frac { 1 \pm \sqrt {1 - 4pq} } {2p} \\
$$

여기서 $q$는 $1-p$ 이므로 
$$
1 - 4pq = 1 - 4p(1 - p) \\
= 1 - 4p + 4p^2 \\
= (2p - 1)^2
$$

$$
x = \frac { 1 \pm \sqrt {(2p - 1)^2} } {2p} \\
x = \frac { 1 \pm (2p - 1) } {2p} \\
x = 1, \frac {2 - 2p} { 2p } = \frac {1 - p} {p} = \frac {q} {p} \\
$$

일반해는 행의 선형 결합으로 표현되기에
$$
p_i = A \times 1 ^ i + B \times \left ( \frac {q} {p} \right ) ^ i \kern{2em}  (p \ne q) \\[2em]

p_0 = 0 = A + B \\
A = -B \\[2em]

p_n = 1 = A + B \left ( \frac {q} {p} \right ) ^n \\[1em]
= A -A \left ( \frac {q} {p} \right ) ^n \\[1em]
= A \left (1 - \left (\frac {q} {p} \right ) ^n \right ) \\[2em]
A \left ( 1 - \left ( \frac {q} {p} \right )^n \right ) = 1 \\[1em]
A = \frac {1} {1 - \left ( \frac {q} {p} \right ) ^n} \\[1em]
B =  - \frac {1} {1 - \left ( \frac {q} {p} \right ) ^n} \\[2em]
p_i = \boxed { \frac {1 - \left ( \frac {q} {p} \right )^i} {1 - (\frac {q} {p})^n} }
$$

$p = q$인 경우는
$$
x = \frac {q} {p} \\[1em]
\lim_{x \to 1} {\frac {1 - x^i} {1 - x^n}} \\[1em]
= \lim_{x \to 1} {\frac {\frac {d} {dx} [1 - x^i]} {\frac {d} {dx} [1 - x^n]}} \\[1em]
= \lim_{x \to 1} {\frac {-ix^{i-1}} {-nx^{n-1}}} \\[1em]
= \boxed { \frac {i} {n}}
$$

몇가지 상황을 시뮬레이션 해보면
- $i = N - i,\ p = 0.49,\ N = 20$이면 $A$가 승리할 확률은 $40$%입니다.
- $i = N - i,\ p = 0.49,\ N = 100$이면 $A$가 승리할 확률은 $12$%입니다.
- $i = N - i,\ p = 0.49,\ N = 200$이면 $A$가 승리할 확률은 $2$%입니다.

### 확률변수
확률변수는 함수이다.

#### 예시1 베르누이 분포
확률변수 $X$가 Bern 분포를 따르면

$X$가 가질 수 있는 값은 $0$과 $1$, 두 개 이고,

X가 1이 되는 사건은 p확률로 갖고 ($P(X = 1) = p$)

X가 1이 되는 사건은 1 - p 확률로 갖는다 ($P(X = 0) = 1 - p$)

#### 예시2 이항분포
이항분포는 $n$개의 독립적인 베르누이 시행에서 성공 횟수의 분포는 $\text {Bin}(n, p)$

확률변수 $X$가 이항분포 $\text {Bin}(n, p)$를 따른다면

$P(X = k) = \binom {n} {k} p^k (1 - p)^(n - k)$

추가로 $X \sim \text {Bin}(n, p),\ Y \sim \text {Bin}(m, p)$ 이면, $X + Y$는 $\text {Bin}(n + m, p)$ 분포를 따른다. 별도의 증명없이 보일 수 있다.
