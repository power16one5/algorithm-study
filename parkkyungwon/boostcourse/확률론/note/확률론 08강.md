### 이항분포
#### 이야기
$X$를 $n$번 독립 수행에서 성공한 횟수로 생각할 수 있다

#### 지시확률변수
$$
X = x_1 + x_2 + x_3 + \cdots + x_n \\[1em]
x_i = \begin{cases} 1 &\text{if i번에 성공일 때} \\ 0 &\text{if i번이 성공 이외 일 때}  \end{cases}
$$

### 확률 변수
$X=7$은 표본공간 $S$에서 샘플을 뽑아보니 7인 사건을 가르킨다.

### 확률질량함수 (Probability Mass Function)
이 함수는 이산확률변수에만 정의 됩니다. 변수에서 나올 수 있는 값이 꼭 정수일 필요는 없고 열거할 수 있어야 합니다. ($a_1, a_2, a_3$)

이 함수는 모든 $j$에 대해 $P(X = a_j) = P_j$의 확률을 정의해야 하고 \
$P_j \ge 0,\ \sum _j P_j = 1$를 만족해야 합니다. 합이 1보다 크면 함수 정의를 잘못한 것이겠죠

#### 이항분포의 확률질량함수(PMF)
$$
P(X=k) = \binom{n}{k} p^k q^{n-k},\ q = 1 - p \\[1em]
$$

#### 이항분포의 PMF가 유효한지 확인
$$
\sum_{k = 0} ^{n} {\binom{n}{k} p^k q^{n-k}} = (p + q)^n = 1
$$

### 누적분포함수 (Cumulative Distribution Function)
$X \le x$도 하나의 사건입니다.

$F(x) = P(X \le x)$이면 $F$는 X의 CDF입니다.

### 이항 분포를 따르는 두 확률변수의 합
이항 분포를 따르는 두 확률변수 $X, Y$가 있다.
$$
X \backsim \text{Bin}(n, p), Y \backsim \text{Bin}(m, p) \\
$$

두 확륣변수를 더했을 때 아래와 같이 됨을 증명해보자
$$
\rArr X + Y \backsim \text{Bin}(n + m, p)
$$

#### 이야기
수학적으로는 두 함수의 합입니다. 두 함수를 합하기 위해선 같은 정의역을 가져야하고, 지금 우리는 이항분포를 따르는 두 함수를 합하면 됨으로 
$ X + Y \backsim \text{Bin}(n + m, p)$는 정확합니다.

#### 지시확률변수을 이용
$$
X = x_1 + x_2 + x_3 + \cdots + x_n \\
Y = y_1 + y_2 + y_3 + \cdots + y_n \\[1em]
X + Y = \sum _{i = 1} x_i + \sum _{j = 1} y_j
$$

이항분포의 정의가 독립적인 베르누이 분포를 합친거였고, 각 $x_i$와 $y_j$는 독립적인 베르누이 분포이므로 $\text {Bin}(n + m, p)$가 됩니다.

#### PMF 이용
$X + Y$의 PMF를 계산해서 합이 성립함을 보여보자

$$
P(X + Y = k) \\
= \sum_{i = 0} ^{k} {P(X + Y = k | X = i)P(X = i)} \\[1em]
= \sum_{i = 0} ^{k} {P(Y = k - i | X = i)} \binom{n}{i} p^i q^{n-i} \\[1em]
= \sum_{i = 0} ^{k} {\binom{m}{k - i}p^{k - i}q^{m - k + i}} \binom{n}{i} p^i q^{n-i} \\[1em]
= p^kq^{m + n - k} \sum_{i = 0} ^{k} {\binom{m}{k - i} \binom{n}{i}} \\[1em]
\sum_{i = 0} ^{k} {\binom{m}{k - i} \binom{n}{i}} = \binom{m + n}{k} \\[1em]
= \boxed {p^k q^{m + n - k} \binom{m + n}{k}} \\[1em]
$$

그리고 $p^k q^{m + n - k} \binom{m + n}{k}$는 정확히 $\text {Bin}(m + n, p)$에서 $k$개 성공할 확률(PMF)이다.

### 예제 1
52장 트럼프 카드에서 5장 뽑을 때 에이스카드가 있을 확률을 구해보자
- 에이스 카드는 4장 있으므로 4장 까지만 뽑을 수 있다.
- 각 시행은 독립이 아니여서 이항분포를 따르지 않는다.

$$
P(X=k), k \in \lbrace 0, 1, 2, 3 , 4 \rbrace \\[1em]
P(X=k) = \frac {\binom {4} {k} \binom {48} {5 - k}} {\binom {52} {5}} \\[1em]
$$

이러한 확률 분포를 초기하 분포라고 하는데  \
$\sum _{k = 0} ^4 \binom {4} {k} \binom {48} {5 - k}$는 방데르몽드 항등식에 의해 $\binom {52} {5}$과 같다.

$$
\sum _{k = 0} ^4 \binom {4} {k} \binom {48} {5 - k} = \binom {52} {5}
$$

따라서 PMF로 유효해 보인다.
