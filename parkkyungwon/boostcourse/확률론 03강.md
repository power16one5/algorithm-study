## 생일 문제
$k$명의 사람이 있을 때 최소 $2$명의 생일이 같을 확률 찾기

#### 조건
- 윤년은 제외, 1년은 365일
- 모든 일자는 생일이 될 확률이 같음
- 쌍둥이 제외

만약 $k > 365$ 이면 확률은 1이 됨 (비둘기집 원리)

그렇기 때문에 $k \le 365$로 가정

한명도 같지 않을 확률을 먼저 구해보자.

$$
P(\text {no match}) = \frac {365 \cdot 364 \cdots (365 - k + 1)} {365^k} \\[1em]
P(\text {match}) = 1 - P(\text {no match})
$$

## Non-Naive (이어서)
- $P(\empty) = 0, \kern {0.5em} P(S) = 1$

- $P(\bigcup _{n = 1} ^{\infin} A_n) = \sum _{n = 1} ^{\infin} P(A_n)$ (단, $A_1, A_2, \cdots, A_n$이 모두 서로소) 

### 속성
- $P(A^c) = 1 - P(A)$. \
proof : $1 = P(S) = P(A \cup A^c) = P(A) + P(A^c)$, since  $A \cap A^c = \empty$

- if $A \sube B$, then $P(A) \le P(B)$. \
proof : $B = A \cup (B \cap A^c)$, disjoint \
$P(B) = P(A) + P(B \cap A^c) \ge P(A)$ since $P(B \cap A^c) \ge 0$

- $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ \
proof : $P(A \cup B) = P(A \cup (B \cap A^c)) = P(A) + P(B \cap A^c)$ \
이제 $P(A) + P(B) - P(A \cap B)$로 유도하고 싶은데, 잘 되지 않는다. 그래서 아래 식을 증명해보자 
$$
P(A) + P(B) - P(A \cap B) \stackrel {?} {=} P(A) + P(B \cap A^c) \\[1em]
P(B) - P(A \cap B) \stackrel {?} {=} P(B \cap A^c) \\[1em]
P(B) \stackrel {?} {=} P(B \cap A^c) + P(A \cap B) \\[1em]
$$
$B \cap A^c$와 $A \cap B$는 서로소다. 그리고 합하면
$$
(B \cap A^c) \cup (A \cap B) \\[1em]
= B \cap (A^c \cup A ) \\[1em]
= B \cap S \\[1em]
= \boxed {B}
$$

### 포함 배제
$P(A \cup B \cup C)$를 구하는 방법은 각 항목을 더하고, 2개 항목이 겹치는 부분을 빼고, 3개 항목이 겹치는 부분을 빼면 된다.

일반화 하면

$$
P(A_1 \cup A_2 \cup \cdots \cup A_n)
= \sum _{i = 1} ^n P(A_i) - \sum _{i < j} P(A_i \cup A_j) + \\
 \sum _{i < j < k} P(A_i \cup A_j \cup A_k) \cdots + \\
 (-1) ^ {n + 1} \sum _{i < j < \cdots < z} P(A_i \cup A_j \cup \cdots \cup A_z)
$$

추가로 확률론 강의와는 무관한 내용을 적어본다.

평소에 코딩할 때 포함 배제관련 코드 짜는것에 부담을 느꼈다. 메모리를 심하게 먹고, 개념이 햇갈리고, 비효율적인 코드가 되었기 때문이다. 

그런데 이 강의를 보고 나니 어떻게 코드를 짜면 효율적인지 생각이 나서 코드를 적어본다.

```python
def in_ex(arr):
    length = len(arr)
    total_dp = [0] * length

    def func(i, depth, w):
        next_depth = depth + 1

        for j in range(i, length):
            w2 = w * arr[j]
            total_dp[depth] += w2
            func(j + 1, next_depth, w2)
    
    func(0, 0, 1)

    total = 0
    for a in total_dp:
        total += a
        total = -total
    
    if total < 0: total = -total

    return total
```

### 디 몽마르트 문제(매칭 문제)
무작위로 섞인 카드 뭉치가 있는데, 카드의 위치와 카드의 숫자가 같은게 최소 1개가 있을 확률을 구한다.

먼저, 특정한 위치에 해당 가드가 있을 화률은 $1/n$이다.

$$
P(A_j) = \frac {1} {n}, \text {naive : } \frac {_{n - 1} P _{n - 1}} {_nP_n} = \frac {(n - 1)!} {n!} = \frac {1} {n} \\[1em]
P(A_1 \cap A_2) = \frac {(n-2)!} {n!} = \frac {1} {n (n - 1)} \\[1em]
\vdots \\[1em]
P(A_1 \cap A_2 \cap \cdots \cap A_k) = \frac {(n - k)!} {n!}
$$

이제 우리가 구하고 싶은 확률을 계산해 보자

$$
P \left ( \bigcup _{i = 1} ^ n A_i \right ) = \binom {n} {1} \frac {1} {n} - \binom {n} {2} \frac {1} {n(n - 1)} + \binom {n} {3} \frac {1} {n(n - 1)(n - 2)} - \cdots \\[1em]
= n \frac {1} {n} - \frac {n(n - 1)} {2!} \frac {1} {n(n - 1)} + \frac {n(n - 1)(n - 2)} {3!} \frac {1} {n(n - 1)(n - 2)} - \cdots \\[1em]
= 1 - \frac {1} {2!} + \frac {1} {3!} - \cdots \\[1em]
\approx 1 - \frac {1} {e}
$$
